# Verified demo

Fixture: `clinical-nlp-1.0.0`, 5,200 synthetic records, 18 fields.

The replay reads `fixtures/clinical_nlp/golden/report.json`, which is generated by the same
Polars engine used by the live API. It must always display a **Verified Demo Replay** badge and
the engine version plus shortened dataset hash.

The demonstration moves from blocked release brief through semantic review, explicit
high-risk dispositions, dry run, deterministic apply, validation, and conditional release.
Exact visible scores and counts come from the report; prose must not duplicate them.

Regenerate after an intentional fixture or engine change:

```bash
.venv/bin/python scripts/generate_golden.py
```
